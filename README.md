## 📌 Project Overview

During my Ontario Public Service internship, I contributed to a
Next-Generation 9-1-1 (NG9-1-1) infrastructure modernization initiative.

The project focused on improving how technical knowledge, data definitions,
schemas, mapping information, and troubleshooting procedures were
organized and accessed by cross-functional technical teams.

---

## 🔎 The Challenge

Critical technical information was distributed across multiple legacy
documentation sources and environments.

This created challenges including:

- Difficulty locating reliable technical information
- Inconsistent data definitions
- Fragmented troubleshooting procedures
- Limited visibility into data relationships and lineage
- Communication delays between technical teams and external vendors

---

## 💡 The Solution

I helped design and implement a centralized enterprise knowledge
repository using:

**Azure DevOps Wiki + SharePoint Online**

The solution organized technical information into a structured and
accessible knowledge-management environment.

### Key Components

- Technical schema documentation
- Data definitions
- Data mapping rules
- Data lineage documentation
- Troubleshooting runbooks
- Root-cause analysis documentation
- Technical workflows
- Centralized reference materials
